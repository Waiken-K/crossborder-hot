
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 产品或服务名 / 政策或表格名 / 项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "Updated requirements"、"Important notice"、"Day 1"、"重磅更新"）时，结合【来源】和正文把主体补进标题。例：原标题 "Updated requirements" + 来源 "Wise Help Centre" → "Wise 更新账户验证要求"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或产品时，用上位词（如“某银行账户验证规则”）兜底，绝不凭行业常识编一个机构、地区、身份条件、数字或日期。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Comparison 这类解释、分析、教程或比较标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的政策、产品或规则，就改写成“发布 / 调整 / 停止 / 开放”。只有原标题或正文明确宣布变化时，中文标题才能使用对应动作。
   例：原标题 "How to update your personal details" + 来源和正文明确是 Wise → "如何在 Wise 更新个人资料"，不能写成 "Wise 调整个人资料规则"。
   例：原标题 "Understanding CRS self-certification" → "CRS 自我证明怎么填、适用于谁"，不能写成 "OECD 发布 CRS 新规"。
