# 工作包 4：读者侧 MVP

工作包 4 把“跨境热点”从通用资讯流推进为双入口产品：

- **热点入口**回答“最近发生了什么”；
- **实用避坑入口**回答“我现在该怎么做、哪些条件容易踩坑”。

## 本次实现

- 新增 `/guides`，汇总被编辑系统标记为“实操/避坑”的精选内容；
- 按账户与资金、税务身份、海外通信、验证与风险四组提供问题导航；
- 页面明确展示四条内容承诺：条件写清楚、优先一手来源、失效内容可追踪、个案不外推；
- 桌面侧栏、手机底部导航、手机“更多”、站点地图和 `llms.txt` 都加入入口；
- 复用现有主题、精选与公开读取层，不增加第二套内容数据库；
- 延续精选内容的绝对发布截止，避免缓存让撤回或定时发布的内容提前/延后出现。

## 数据进入条件

内容只有同时满足以下条件，才会出现在“最新实操与避坑”：

1. 已通过跨境领域预筛与双次评分；
2. 被标记为 `实操/避坑`；
3. 已公开发布且没有撤回；
4. 来源不是仅参与热度的 `hot_signal`；
5. 读者端只展示公开摘要、来源与原文链接。

下一步应使用一批真实 Wise、ITIN、美卡和 eSIM 样本检查页面信息密度，并根据用户点击与收藏行为调整入口顺序，而不是先增加更多视觉组件。
