# 跨境热点信号源方案

首批来源池来自运营飞书表“来源雷达”。2026-10-03 读取到 85 个启用来源：16 个 S 级监管/一手规则源、56 个 A 级官方公告/条款源、8 个 B 级可信媒体、5 个 C 级社区线索。

## 接入原则

1. **规则事实优先一手来源。** 监管机构、官方公告和帮助中心可以直接成为事实证据；媒体用于发现和旁证；X 与论坛只生成线索。
2. **先验证，再启用。** 只有 RSS/Atom 能正常解析，或网页列表的标题、链接、日期选择器已经试抓通过，才默认启用。
3. **社区个案不外推。** X 和论坛默认使用 `hot_signal`，不单独出现在公开信息流；必须补到官方规则或多个独立证据，才进入编辑结论。
4. **不为数量牺牲稳定性。** 帮助中心、条款页如果没有稳定更新列表，先留在来源池，后续通过专用适配器或变更监控接入。

## 工作包 3 首批配置

`industry/sources.json` 现在包含：

- 8 个默认启用且已试抓通过的官方源：Wise Status、SEC、FINRA、CFPB、IRS、HKMA、IRAS、OFAC；
- 4 个来自飞书来源池的 X 线索源，配置已落库，但在设置 `SOCIALDATA_API_KEY`、请求预算和失败告警前保持暂停；
- 所有来源默认只展示摘要并回链原文，不转载全文。

## 飞书等级到系统字段

| 飞书等级 | 系统设置 | 用法 |
|---|---|---|
| S·一手规则/监管 | `tier=T1`, `first_party=true`, `editorial` | 可作为规则事实的首要证据 |
| A·官方公告/条款 | `tier=T1`, `first_party=true`, `editorial` | 只对发布主体自己的产品或服务成立 |
| B·可信二手 | `tier=T2`, `first_party=false`, `editorial` | 发现、解释和交叉验证，入选门槛更高 |
| C·线索 | `tier=T2`, `first_party=false`, `hot_signal` | 只参与热度和选题发现，不单独形成结论 |

## 下一批顺序

1. Wise、Revolut、N26、Red Pocket 等帮助中心的条款变更监控；
2. 路透、彭博、财新等媒体发现层；
3. 美卡论坛等社区 DP 的“多用户异常集中”检测；
4. 其余监管与产品官网，按 ITIN / CRS / 美卡 / eSIM 四条主线逐批试抓。

来源池的飞书链接不写入公开仓库，避免把内部运营表 token 当作产品配置。新增来源仍应先在后台“预览抓取”，确认标题、原文链接和日期，再启用自动采集。
